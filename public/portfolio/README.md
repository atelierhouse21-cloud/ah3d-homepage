# 포트폴리오 사진 폴더

이 폴더에 사진을 올리면 홈페이지 포트폴리오 섹션에 자동으로 나타납니다.

## 파일 이름 규칙

```
01_정밀 기계 부품.jpg   →  화면에 "정밀 기계 부품" 으로 표시
02_경량화 설계.jpg      →  화면에 "경량화 설계" 로 표시
```

- 맨 앞 숫자는 표시 순서를 정합니다. 화면에는 나오지 않습니다.
- 새 작업을 맨 앞에 두려면 `00_` 으로 시작하세요.
- 숫자 뒤의 글자가 그대로 제목이 됩니다.

## 사진 조건

| 항목 | 권장값 |
|---|---|
| 형식 | JPG |
| 가로 크기 | 1200px 내외 |
| 용량 | 장당 300KB 이하 |
| 비율 | 가로가 세로보다 긴 형태 |

사진은 흑백으로 변환되어 표시됩니다. 어두운 무채색 배경에서
같은 조명으로 찍으시면 나열했을 때 가장 정돈되어 보입니다.

## 사진을 지우고 싶을 때

GitHub에서 해당 파일을 열고 휴지통 아이콘을 누르면 됩니다.
폴더를 통째로 비우면 임시 사진이 다시 나타납니다.
