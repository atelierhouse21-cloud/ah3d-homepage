## 수정 내용 — Footer 최하단 메뉴 삭제

Footer(최하단)에 상단 메뉴(3D 프린팅 / 모델링 / 설계·제작 / 포트폴리오 / 가이드)와
똑같은 목록이 중복으로 나오고 있었습니다. 상단 메뉴는 그대로 두고, Footer 쪽만
삭제했습니다.

**수정한 파일 2개:**

- `components/home/Footer.tsx` — 메뉴 목록을 그리던 `<nav className="foot-nav">`
  블록을 지웠습니다. (상단 메뉴를 그리는 `components/TopBar.tsx`는 건드리지
  않았습니다 — 완전히 별개 파일이라 그대로 살아있습니다.)
- `app/globals.css` — Footer가 "브랜드 | 메뉴 | 사업자 정보" 3칸 구조였는데,
  가운데 메뉴 칸이 없어졌으니 "브랜드 | 사업자 정보" 2칸 구조로 바꿨습니다.
  (`.foot-grid`, `.foot-nav` 관련 규칙 수정)

GitHub에 반영하실 때는 이 두 파일만 같은 경로에 덮어쓰시면 됩니다.
