## 수정 내용 — `/portfolio` 페이지의 분류 탭 변경

기존: 전체 / 3D Printing / 3D Modeling / Mechanical / Prototype
변경: 전체 / 3D프린팅 / 3D모델링 / 설계·제작

말씀하신 대로 Mechanical과 Prototype 두 탭을 "설계·제작" 하나로 합치고,
영어로 되어 있던 나머지 탭도 한글("3D프린팅", "3D모델링")로 바꿨습니다.

**수정한 파일 1개:**

- `components/PortfolioGrid.tsx`

**중요 — 필터링 방식이 함께 바뀌었습니다.**

예전에는 `lib/cases.ts`에 등록된 항목의 `tags`로 분류를 매칭했는데,
지금은 `lib/cases.ts`를 더 이상 쓰지 않기로 하셨으므로(빈 객체 상태),
이번 수정에서 분류 매칭 방식도 **사진 파일명의 분류 칸**을 직접 보도록
바꿨습니다.

즉, `public/portfolio/` 사진 파일명이

```
설계제작_더치머신v1 .jpg   → 분류: 설계제작 → "설계·제작" 탭에서 보임
3D프린팅_로봇개 골격.png   → 분류: 3D프린팅 → "3D프린팅" 탭에서 보임
```

이런 식으로 되어 있으면 자동으로 해당 탭에 매칭됩니다. ("설계·제작"
탭 이름의 가운뎃점은 비교할 때 무시하므로, 파일명은 "설계제작"처럼
가운뎃점 없이 쓰셔도 됩니다.)

지금 폴더에 있는 사진 5장은 전부 "설계제작" 분류라, "설계·제작" 탭을
누르면 5장 모두 선명하게 나오고 "3D프린팅"·"3D모델링" 탭을 누르면
전부 흐리게(비매칭) 표시됩니다 — 정상 동작입니다. 나중에 3D프린팅이나
3D모델링 작업 사진을 올리실 때 파일명 맨 앞 분류만 맞춰 주시면 자동으로
해당 탭에 걸러집니다.

GitHub에 반영하실 때는 이 파일 하나만 같은 경로에 덮어쓰시면 됩니다.

으로 나오고, "설계·제작" 탭 클릭 시 해당 사진들이 정상적으로 강조되는
것을 확인했습니다.
