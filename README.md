## 참고 — 이메일 링크를 누르면 "브라우저만 열리는" 현상

코드 버그가 아니라 **컴퓨터/브라우저 환경 설정** 때문입니다.

`atelierhouse21@gmail.com →` 링크는 `mailto:` 링크로 되어 있습니다.
`mailto:` 링크를 클릭하면 브라우저가 아니라 **운영체제에 기본으로
지정된 메일 프로그램**(Outlook, Apple 메일 등)을 새로 여는 것이 원래
동작입니다. 그런데:

- 컴퓨터에 기본 메일 프로그램이 지정되어 있지 않으면, 브라우저가
  "메일 앱을 여시겠습니까?" 같은 안내만 띄우거나 아무 반응이 없을 수
  있습니다. (이게 "브라우저만 열린다"고 느껴지는 이유일 가능성이 높습니다.)
- Gmail을 웹으로만 쓰고 데스크탑 메일 앱을 따로 설치/설정하지 않은
  경우 흔히 발생합니다.

**해결 방법(사용자 컴퓨터 설정, 코드 수정 아님):**
- Chrome: 주소창 오른쪽 자물쇠 아이콘 → 사이트 설정 → "처리기" 항목에서
  Gmail을 기본 mailto 처리기로 허용/등록할 수 있습니다.
- 또는 Windows/Mac 설정에서 기본 메일 앱을 지정하면, 이후로는 그 앱이
  바로 열립니다.

즉, 방문자의 컴퓨터에 메일 프로그램이 연결되어 있다면 정상적으로
작성 화면이 뜨는 구조라, 코드 상 수정할 부분은 없습니다.
