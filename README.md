# AH3D 홈페이지 — 히어로 이미지 제거 + 버튼 3개를 히어로 우측으로 이동 (2026-09-30)

이번 zip은 **수정 1건**만 담겨 있습니다.

## 수정 내용

히어로 문구 옆에 있던 CAD 도면 스타일 이미지(치수선, DETAIL A 등)를
완전히 제거하고, 그 자리에 원래 하단에 가로로 나열되어 있던 버튼 3개
("3D 프린팅 견적" / "3D 모델링 의뢰" / "부품·시제품 상담")를 세로로
쌓아 배치했습니다.

- 왼쪽: 기존과 동일한 히어로 문구(제목 + 설명)
- 오른쪽: 버튼 3개가 세로로 쌓인 카드 목록
- 모바일에서는 기존처럼 문구 아래로 버튼이 세로로 이어집니다.

**수정한 파일 2개:**

- `components/home/HeroSection.tsx` — CAD 도면을 그리던 `HeroDrawing()`
  함수와 `<image href="/hero/part-bracket.png" .../>` 참조를 전부
  삭제했습니다. 버튼 목록(`<nav className="hero-paths">`)을 히어로
  하단에서 히어로 문구 옆(오른쪽 칸)으로 옮겼습니다. 버튼 데이터
  자체(`HERO_PATHS`, `lib/home.ts`)는 수정하지 않았습니다.
- `app/globals.css` — `.hero-top`을 "왼쪽 문구 / 오른쪽 버튼 목록" 2단
  레이아웃에 맞게 조정하고, `.hero-paths`를 가로 3열이 아닌 세로 1열
  카드 목록으로 바꿨습니다. 더 이상 쓰지 않는 `.hero-cad` 관련 규칙은
  삭제했습니다.

**참고:** `public/hero/part-bracket.png` 이미지 파일 자체는 삭제하지
않았습니다(그냥 더 이상 코드에서 참조하지 않을 뿐입니다). 나중에 다시
쓸 일이 없다면 GitHub에서 그 파일만 따로 지우셔도 되고, 그냥 두셔도
사이트 동작에는 영향이 없습니다.

GitHub에 반영하실 때는 이 두 파일만 같은 경로에 덮어쓰시면 됩니다.

## 확인 방법

로컬에서 빌드 후 데스크탑(1440px)·모바일(390px) 화면 모두 스크린샷으로
직접 확인했습니다. 이미지는 완전히 사라지고, 버튼 3개가 데스크탑에서는
문구 오른쪽에 세로로, 모바일에서는 문구 아래에 세로로 자연스럽게
배치됩니다.
